# Interstellar2060

An interstellar exploration game for Android.

**[Download Interstellar2060.apk](../../raw/main/Interstellar2060.apk)** — install directly, no Play Store.

Package `com.happyoyster.interstellar`. Android 8.0 (API 26) or newer.

## Source

Not in this repository. The build tree was not kept, and the APK is the only
surviving copy — so this repo ships the app itself rather than a decompile
that would not match what was actually written.
